# Simple Shooter
Ek simple 2D shooting game (HTML5 Canvas) + Capacitor thi Android APK.

- Left side drag = move, right side touch = manual aim + fire
- "Auto-aim" button: ON = nearest enemy par smooth lock + auto fire
- PC test: WASD move, mouse hold = aim/fire

## APK build
Repo GitHub par push karo -> Actions tab -> "Build APK" -> artifact `simple-shooter-apk` download karo.
